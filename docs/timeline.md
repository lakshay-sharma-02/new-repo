# Semester Timeline

## Overview

| Phase | Weeks | Focus |
|---|---|---|
| **Discovery** | 2–5 | Research, empathy, problem framing |
| **Ideation** | 6–7 | Brainstorm, screen, concept selection |
| — | 8 | **Mid-Term Exams (no project work)** |
| **Design** | 9–11 | Wireframes → prototype |
| **Validation** | 12–13 | Test prototype, iterate |
| **Delivery** | 14 | Final report, presentation, demo |

---

## Week-by-Week Plan

### Phase 1: Discovery (Weeks 2–5)

| Week | Task | Deliverable |
|---|---|---|
| **2** | Set up project structure, define research plan, draft interview guide + survey | Interview guide, survey template, this timeline |
| **3** | Begin laundry cycle observations (Cycle 1), start hosteller interviews (target: 3–4) | Observation notes, interview transcripts |
| **4** | Continue observations (Cycle 2), interview service staff (target: 2), distribute survey | Staff interview notes, survey responses |
| **5** | Complete observations (Cycle 3), finish hosteller interviews (8+ total), synthesize research | Completed observations, full interview set, raw insights |

### Phase 2: Ideation (Weeks 6–7)

| Week | Task | Deliverable |
|---|---|---|
| **6** | Create persona, empathy map, user journey map, identify failure points | Persona, empathy map, journey map, failure-point list |
| **7** | Write POV + HMW statements, brainstorm ideas (15+), build screening matrix, select concept | POV/HMW, idea log, screening matrix, concept choice |

### Mid-Term Break (Week 8)
No project work.

### Phase 3: Design (Weeks 9–11)

| Week | Task | Deliverable |
|---|---|---|
| **9** | Low-fi wireframes in Figma (key screens: submit, track, dispute) | Lo-fi wireframes |
| **10** | Iterate wireframes based on internal review, begin hi-fi mockups | Revised wireframes, hi-fi screens |
| **11** | Complete hi-fi Figma prototype (clickable), document design decisions | Hi-fi prototype, figma-notes.md |

### Phase 4: Validation (Weeks 12–13)

| Week | Task | Deliverable |
|---|---|---|
| **12** | Recruit test users (5+ hostellers), conduct usability tests, capture feedback | Test sessions, feedback capture matrix |
| **13** | Analyze feedback, iterate prototype, document changes, build lightweight working demo | Iteration log, working demo (basic) |

### Phase 5: Delivery (Week 14)

| Week | Task | Deliverable |
|---|---|---|
| **14** | Write final report, prepare presentation, polish demo, compile all deliverables | Final report, presentation, demo |
